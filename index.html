🔗 إعدادات الربط السحابي مع Google Sheets

تجهيز المزامنة السحابية للعيادة:
  1. قم بإنشاء جدول بيانات (Google Sheet) فارغ على حساب جوجل الخاص بك.
  2. افتح قائمة (Extensions / الإضافات) ثم اختر Apps Script.
  3. قم بنسخ محتوى الكود المحدث بالكامل في ملف GoogleAppsScript.js ولصقه في محرر الأكواد، ثم حفظ ونشر Deploy -> New deployment كـ Web app وإتاحة الوصول للجميع (Anyone).
  4. انسخ رابط الويب المتولد وضعه في الحقل أدناه لتفعيل المزامنة.

📦 نسخ احتياطي وتفريغ البيانات محلياً

يمكنك تصدير قاعدة البيانات المحلية بالكامل كملف JSON لحفظها، أو استيرادها لاسترجاع البيانات في ثوانٍ، أو مسح قاعدة البيانات للبدء من جديد.
